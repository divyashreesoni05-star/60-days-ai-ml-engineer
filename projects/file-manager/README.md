# 📂 Python File Manager (CRUD Operations)

## 🚀 Overview

This is a beginner-friendly Python project that performs basic file operations using CRUD functionality.

It allows users to:

* Create a file
* Read a file
* Update a file
* Delete a file

---

## 🛠️ Features

* 📄 Create new files with custom content
* 👀 Read existing file data
* ✏️ Update file (Rename, Overwrite, Append)
* ❌ Delete files
* 📁 Display all files and folders

---

## 🧠 Concepts Used

* File Handling in Python
* Exception Handling
* `pathlib` module
* `os` module
